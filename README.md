\# AI Email Assistant



A Python tool that reads your Gmail inbox, summarizes emails using AI, and generates draft replies.



\## Features



\- Reads emails from Gmail

\- Summarizes each email using AI (OpenRouter - free)

\- Generates draft replies automatically

\- Saves results to JSON file
